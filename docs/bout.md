# 设计 B:行走过程中的动态代偿(2026-10-08 起)

主线不变:医生注意力区域决定**量哪里**,时间决定**什么时候**。相位实验(`docs/gait_phase.md`)证明
ASD 的代偿在一个步态周期内是静态的,这里把时间尺度换成**一次行走的开始到结束**,临床文献说 ASD 的动态
代偿发生在这个尺度(Severijns 2021 Spine J;Eur Spine J 2022 dSVA;Spine Deformity 2026 躯干伸肌耐力)。

## 数据事实(2026-10-08 盘点)

- **短片段的编号就是时间顺序**。35 个 session 里相邻编号的行进方向交替率中位 0.97(来回折返走,
  RLRLRL…),所以把每个片段已算好的量按编号排列就是患者在一次录像里的轨迹,**零新处理**。
  每名患者片段数中位 10,范围 2–86;≥ 6 段的 53 人(ASD 36 / non-ASD 17)。
- 侧视长录像 `raw_data/<类>/whole_video_unprocessed/<日期>/full_lat*.mp4`:ASD 57 条(中位 205 s,
  33 条 ≥ 720p,其余 480×480)、DHS 18、LCS 9、HipOA 2。固定侧视机位,患者在视野里来回走过,
  每次几秒,相隔十几秒;录像开头常有一段空白,时间原点取第一次经过。是带反光标记点的运动捕捉实验室,
  **常有陪同人员同框**(DHS 例 67% 的经过、用助行器的 ASD 例 86%),需要认人。
- 正常人 `raw_data/normal`:19 人 × 2 次 × 侧视 / 正视,1080p 59.94 fps,每条约 10 min,未处理。
  **全部是年轻人**,只能作流水线标定、斜率噪声地板、结构预训练与单向特异性检查,不能作类别或正常值参照。
- 患者短片段 `lat` 的帧率按类别不同:ASD 23.98、DHS 30、LCS / HipOA 59.94;512 数据集靠复制帧凑成 30 fps。

## 零成本版本:`analysis/bout_from_clips.py`(3D 测量,67 人)

每名患者:片段级值 = 各段均值;按编号排序,时间轴 = 归一化秩;`slope` = 对秩的最小二乘斜率(= 首尾总变化),
`lastfirst` = 末 1/4 减 首 1/4,`rho` = Spearman,`z` = 斜率相对片段顺序打乱零分布的 z,`sd_resid` = 去趋势波动。

| 量 | 静态均值 AUC | 行走中变化(最好的一个) | 方向 |
|---|---|---|---|
| 躯干前倾 | 0.797 | rho 0.688,p 0.029 | 两组都随行走增加(ASD 89%、non-ASD 71% 斜率为正),ASD 更强 |
| 肩偏移 | 0.806 | rho 0.735,p 0.006 | 同上 |
| 头前伸 | 0.534 | 无 | 去趋势波动 ASD 更小(0.631) |
| 髋屈最大 | 0.698 | 无 | 去趋势波动 ASD 更小(0.665,p 0.055) |
| **髋活动度** | **0.534** | **slope 0.765,p 0.002;lastfirst 0.714;rho 0.740** | **non-ASD 行走中髋活动度增大(+1.7°),ASD 不变(−0.2°)**;去趋势波动 ASD 更小(0.742,p 0.005) |

读法:"走着走着越来越前倾"是老年患者的普遍现象,不是 ASD 特有;ASD 特有的是**髋的动态是僵的**:
其他老年患者行走中髋关节逐渐活动开,ASD 没有,逐段波动也更小。与相位实验里"头前伸周期内调制更小"同一主题。

验证(`bout_checks.py`,作业目录):
- 片段顺序打乱 30 次:髋活动度 slope 的零分布 AUC 0.517 ± 0.081,真实值 30 次全部超出;trunk_lean rho 97%,shoulder_offset rho 100%。
  `sd_resid` 与顺序无关(零分布 = 真实值),它是变异性信号不是趋势信号。
- 片段数:ASD 中位 8,non-ASD 18(p 0.17);斜率与片段数 Spearman 0.24;只看 ≥ 10 段的 36 人 AUC 0.724。
- **2D 骨架不复现**:2D 的髋活动度 slope AUC 0.392(p 0.21),trunk_lean rho 0.551;3D 与 2D 斜率在患者上 Spearman 0.27。
  变化只有 1–2°,2D 投影的髋角噪声可能淹没它,也不能排除 3D 伪影 —— 需要独立来源复现(下节)。
- 分类(10 份划分):静态 5 量 0.695,+ 斜率 0.699,+ 末-首 0.673,只动态 0.63–0.65,顺序打乱 0.695。
  14 人片段不足用中位数填,5 个斜率里只有髋活动度有信号,其余是噪声,所以整体没涨。
- 多重比较:5 量 × 5 指标 = 25 次检验,髋活动度 slope 的 p 0.002 刚好在 Bonferroni 线上;三个指标方向一致。

## 独立复现:侧视长录像 + YOLOv8-pose(`analysis/bout_trunk.py`,`pegasus/bout_trunk_job.sh`)

逐帧 2D 关键点(取画面里最大的人),矢状面躯干前倾 / 头前伸 / 肩偏移;经过 = 连续检出段,
**逐帧行进方向**由髋中点 x 的平滑速度决定(整段一个符号会在视野内掉头时把一半帧算反),速度太小的帧丢弃,
|躯干角| > 60° 的帧(边缘半露、检错人)丢弃,经过内取中位数。CPU 验证(yolov8n,stride 3):

- 噪声地板:年轻正常人 |斜率| 的 95 分位,躯干前倾 0.09 °/min;超过它的患者 ASD 88%、non-ASD 67%。
- 两个独立来源(长录像 + YOLOv8-pose 2D vs 短片段顺序 + SAM-3D-Body 3D)在同一患者上的"末-首"变化:
  躯干前倾 Spearman **+0.56**(静态均值 +0.95),肩偏移 +0.55,头前伸 +0.28,髋屈最大 +0.38,**髋活动度 +0.17**(静态均值也只有 +0.53)。
- 轨迹图 `docs/figs/bout_trajectories.png`:ASD 的躯干前倾到录像 70% 处比开头多 2.4°,non-ASD 约 1°,年轻人平直。

**结论**

1. **"行走中躯干逐渐前倾"是真的**,两个来源都看到,远高于年轻人的噪声地板,ASD 比其他老年患者强(0.54 对 0.05 °/min),
   与三维步态分析的临床文献一致。这是单目视频第一次量到它。但作为分类特征它弱于静态躯干前倾(0.68–0.71 对 0.78–0.80),
   短片段版加进逻辑回归只有 +0.004。
2. **髋活动度的"动态僵硬"没有复现**:长录像 2D 上两组斜率相同,与 3D 片段版的相关只有 0.17;而且 2D 髋活动度的静态值
   与 3D 的相关也只有 0.53,说明 2D 髋角本身测不准。它目前是"仅见于 3D 片段数据的观察",要确认只能在长录像的经过上
   跑 SAM-3D-Body(流水线在合作者手里,本机没有)。
3. 头前伸没有动态差异。

### 髋活动度信号的来源:步长(2026-10-09)

- **短片段就是长录像里的经过**:81 条长录像检出的经过数 / 该 session 片段数 中位 1.06(20170130:24 / 24)。
  所以在原始长录像上重跑 SAM-3D-Body 量的是同一批经过、同一个模型,不构成独立复现,不做。
  本机有 SAM-3D-Body:conda 环境 `sam_3d_body`,权重 `/work/1/SKIING/chenkaixu/ckpt/sam-3d-body-dinov3`,
  代码与作业脚本在 `Ski3DPose_PyTorch`(`pegasus/run_sam3d_body_luoxi.sh`)。
- 髋活动度的行走中变化与**步长**的行走中变化相关 0.54;回归掉步长与步速的变化后,髋活动度剩余 AUC 0.60(p 0.23)。
  分半信度(奇 / 偶片段各算斜率):躯干前倾 0.69,步长 0.60,髋活动度 0.42。
- **步长的行走中变化**(片段顺序版,53 人):

  | | ASD | non-ASD | p | AUC | 顺序打乱 50 次 |
  |---|---|---|---|---|---|
  | 3D(SAM-3D-Body) | −0.009 | +0.026 | 0.007 | 0.73 | 0.47 ± 0.09,50 / 50 低于真实值 |
  | 2D(另一姿态模型,同一批片段) | −0.017 | +0.031 | 0.002 | 0.76 | 0.48 ± 0.07,50 / 50 |

  同一患者 2D 与 3D 的步长斜率 Spearman **0.92**(髋活动度斜率只有 0.27)。
- 读法:**其他老年患者走着走着步子迈开了,ASD 没有,略有缩短**;髋活动度只是跟着步长走。这是两个姿态模型一致、
  有顺序打乱对照的信号,比"髋僵硬"站得住。与躯干前倾越走越大是同一幅图:ASD 行走中躯干前倾加重、步长不增。
- 分类:只用步长斜率 0.663(AUC 0.727);加进静态 5 量反而 0.717 → 0.667(14 人片段不足用中位数填)。
  它是描述性 / 临床发现,不是分类增益。长录像那条 2D 流水线目前没算步长,要做第三个来源需要在 `bout_trunk.py` 加步长后重跑(约 2 小时)。

### 把现象用进模型(2026-10-09,`analysis/bout_pooling.py`)

疲劳感知聚合:患者级只看 / 偏重行走后段的片段(片段 ≥ 4 的患者;其余用全部)。

| 聚合 | 5 量 LR | B0 | M0 | A1 | TimeSformer |
|---|---|---|---|---|---|
| 全部 | 0.695 / 0.774 | 0.640 / 0.668 | 0.652 / 0.696 | 0.588 / 0.628 | 0.629 / 0.709 |
| 前半 | 0.694 / 0.764 | 0.640 / 0.677 | 0.667 / 0.706 | 0.595 / 0.633 | 0.626 / 0.705 |
| 后半 | 0.693 / 0.776 | 0.636 / 0.666 | 0.651 / 0.685 | 0.573 / 0.624 | 0.610 / 0.711 |
| 末 1/4 | 0.696 / 0.777 | 0.629 / 0.669 | 0.628 / 0.682 | 0.569 / 0.623 | 0.621 / 0.710 |
| 线性偏后 | 0.684 / 0.775 | 0.640 / 0.670 | 0.655 / 0.687 | 0.584 / 0.626 | 0.621 / 0.710 |

(平衡准确率 / AUC;视频三种子均值,67 人。这里的"全部"是先片段均值再患者均值,所以 5 量 LR 是 0.695 而不是主表的 0.717。)

全部持平。连同"斜率作特征"(0.717 → 0.667),两种最直接的用法都没有增益。原因是效应大小:静态躯干前倾组间差约 5°,
行走中漂移的组间差约 1.5°、分半信度 0.6–0.7;只取后段还让每人数据减半。未跑的两种(经过序列 token 模型、证据门控第三分支)
预期也在 0.01 以内。**它在模型里的位置是输出端的可解释报告**(该患者行走中躯干前倾 / 步长的变化曲线),不是精度。

**对新研究的含义**:设计 B 的可靠产出是"单目视频可量化 ASD 行走中的矢状面动态恶化",这是一个测量学 / 临床发现,
分类增益不是它的卖点。要成为论文,最有力的验证对象是同一实验室的运动捕捉(录像里患者贴着标记点)或两点躯干装置:
若能拿到同 session 的 mocap 躯干倾角,就是"单目视频对 mocap 的动态对线验证",这是文献里空缺的。
多人同框的 35 条录像(DHS / LCS 为主)需要跟踪 + 衣着匹配才能纳入,会把 non-ASD 从 18 人补到 30 人左右。
