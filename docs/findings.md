# 结论汇总:哪些说法有证据,哪些被证伪

数据截止 2026-07-31。任务为 ASD vs non-ASD 二分类(三分类已放弃,见
[`why_binary.md`](why_binary.md))。评估协议:5 折按患者分组、train/val/test 三分互不相交、
0 泄漏;5 折的 test 集恰好划分全部 **79 个患者**,每人被且只被一个"没见过他"的模型
预测一次,因此可直接汇总成 79 个独立预测(等价于留一患者的覆盖)。

指标由 `analysis/patient_level_stats.py` 产出:段级预测按患者取概率均值软投票聚合,
macro 给 bootstrap 区间、micro 给 Wilson 区间,配置间做 McNemar 精确检验。

---

## 一、分类:所有配置统计不可区分

患者级 macro(平衡准确率),3 个种子(42/1337/2024)概率平均后聚合,n=79 患者
(ASD 54 / non-ASD 25),多数类基线 0.500:

| 配置 | macro [95% CI] | micro [95% CI] |
|---|---|---|
| A4_no_prior(先验全关) | 0.670 [0.554, 0.782] | 0.696 [0.588, 0.787] |
| A1_no_grounding | 0.654 [0.549, 0.756] | 0.747 [0.641, 0.830] |
| B4_clip_old | 0.649 [0.535, 0.761] | 0.696 [0.588, 0.787] |
| G3_random_map(随机位置) | 0.649 [0.531, 0.763] | 0.696 [0.588, 0.787] |
| D1_doctor1_only | 0.638 [0.522, 0.750] | 0.696 [0.588, 0.787] |
| M1_concept_cliptext | 0.637 [0.525, 0.749] | 0.709 [0.601, 0.797] |
| A3_no_concept_loss | 0.635 [0.528, 0.744] | 0.722 [0.614, 0.808] |
| A0_shuffle_region | 0.627 [0.515, 0.739] | 0.696 [0.588, 0.787] |
| M0_concept_learned | 0.624 [0.520, 0.731] | 0.722 [0.614, 0.808] |
| B0_3dcnn | 0.620 [0.504, 0.733] | 0.671 [0.561, 0.764] |

McNemar 配对检验(同一批 79 个患者,双侧精确):

| 对比 | 独对数 | p |
|---|---|---|
| B0_3dcnn vs M0 | 10 : 14 | 0.541 |
| A1_no_grounding vs M0 | 8 : 6 | 0.791 |
| M0 vs A0_shuffle_region | 6 : 4 | 0.754 |
| M0 vs G3_random_map | 9 : 7 | 0.804 |
| M0 vs A4_no_prior | 14 : 12 | 0.845 |
| M0 vs A2_no_presence | 9 : 7 | 0.804 |

**没有任何一对配置在分类上显著不同**,包括"有临床先验 vs 完全没有先验"。

### 为什么:训练随机性大于配置间差异

同一配置跨种子的波动最大达 **0.125**,比任意两个配置之间的差距都大:

| 配置 | s42 | s1337 | s2024 |
|---|---|---|---|
| B0_3dcnn | 0.720 | 0.563 | 0.641 |
| M0_concept_learned | 0.655 | 0.547 | 0.547 |
| A1_no_grounding | 0.707 | 0.592 | 0.629 |
| G3_random_map | 0.570 | 0.669 | 0.544 |

排序随种子完全翻转。**任何基于单一种子的分类排序都不可信。**

### 结论

论文中分类结果只应报告"各方法与基线统计等价",**不得作任何优劣声明**。
瓶颈是样本量(79 个患者、非 ASD 仅 25 人)与训练方差,不是方法。

## 二、可解释性:差异远超噪声,是唯一站得住的主张

五折均值 ± 标准差(seed 42)。`attn_align` 的零信息下界(uniform)是 **0.068**:

| 配置 | attn_align | region_ap | region_f1_any |
|---|---|---|---|
| **M0_concept_learned** | **0.537 ±0.012** | **0.818 ±0.077** | 0.763 |
| M1_concept_cliptext | 0.529 ±0.008 | 0.808 ±0.071 | 0.762 |
| A2_no_presence | 0.525 ±0.006 | **0.468 ±0.114** | 0.559 |
| A0_shuffle_region | **0.267 ±0.019** | **0.402 ±0.034** | 0.560 |
| A4_no_prior | 0.122 ±0.071 | 0.444 ±0.037 | 0.602 |
| A1_no_grounding | **0.118 ±0.073** | 0.757 ±0.093 | 0.780 |
| G3_random_map | **0.065 ±0.001** | 0.770 ±0.090 | 0.778 |

外部参照(`analysis/eval_attention_alignment.py`,5 折,B0_3dcnn 的最佳 checkpoint):

| 参照 | 对齐度 |
|---|---|
| Grad-CAM | 0.135 ±0.034 |
| center 中心先验 | 0.144 ±0.025 |
| random / uniform | 0.068 ±0.001 |

### 有证据的四条

1. **模型学到的空间对齐远高于所有参照。** M0 = 0.537,是 Grad-CAM(0.135)的 4.0 倍、
   中心先验(0.144)的 3.7 倍、零信息下界(0.068)的 7.9 倍。标准差仅 0.012,
   比分类指标稳定一个数量级。

2. **事后解释方法在本任务上无效。** Grad-CAM(0.135)与"假设人在画面中央"这个
   平凡先验(0.144)无差别。所以可解释性不能靠事后方法补,必须显式监督。

3. **空间对齐只能由 grounding 监督产生,且必须来自真实医生标注。**
   - 去掉 grounding(A1):0.537 → 0.118,几乎回到下界 → 分类训练本身产生不了
   - 目标随机平移到解剖上无意义的位置(G3):**0.065**,精确等于零信息下界 → 学不到任何对齐
   - 区域错配但仍落在真实解剖上(A0):0.267 → 部分保留
   
   三点构成梯度,说明模型学的是真实的解剖—概念对应,不是任何形式的空间记忆。

4. **先验的两个成分完全解耦。** 存在性监督负责"是哪些区域"(去掉后 region_ap
   0.818 → 0.468,而 attn_align 几乎不变);grounding 负责"在画面哪里"(去掉后
   attn_align 0.537 → 0.118,而 region_ap 仍有 0.757)。

## 三、被证伪的说法(不得写入论文)

以下都曾在中间阶段被报告过,后被更正的协议或统计口径推翻:

| 曾经的说法 | 推翻它的证据 |
|---|---|
| 三分类可行 | LCS_HipOA 仅 9 个患者,患者互不相交后每折 test 剩 1-2 个,全部模型该类召回 0.00-0.06 |
| 主方法优于/劣于 3D CNN 基线 | McNemar p=0.541,统计等价 |
| grounding 损害分类 | McNemar p=0.791,统计等价 |
| 打乱区域使分类下降 | p=0.754 |
| 临床先验提升分类 | p=0.845(单种子下曾得 p=0.006,是种子噪声) |
| 精度与可解释性存在可调前沿 | grounding 权重扫描:0 → 0.1 时 attn_align 从 0.118 跳到 0.550,之后 0.1 → 5.0 仅从 0.550 缓降到 0.522。是开关不是旋钮 |
| 分类代价是临床对齐特有的 | G3 随机位置代价相同(p=0.804),代价来自"存在空间约束"本身 |

### 五次架构干预均未改变格局

| 干预 | 假设 | 结果 |
|---|---|---|
| grounding 权重扫描(6 点) | 存在可调前沿 | 阶跃,非前沿 |
| G0_global_raw | 全局通路受 256 维瓶颈所限 | 更差(0/5),退化到 A4 水平 |
| G1_spatial_ground | 时间约束无信息(CV=0.043) | 更差(0/5 vs A1) |
| G2_background | 区域外证据无处安放 | 更差(0/5 vs A1) |
| G3_random_map | 代价是医生区域特有 | 代价相同,但对齐归零 |

已排除的机制:token 分辨率(7×7 与 28×28 的区域间重叠 0.135 vs 0.127,区域仍可分)、
注意力温度(收敛于 13-14,远未饱和)、全局通路宽度、时间约束、额外自由度。

## 四、必须一并披露的限制

- **样本量**:79 个患者,非 ASD 侧仅 25 人;每折 test 的 non-ASD 只有 4-6 人。
- **统计口径**:指标须报患者数(n=79),不得报段数(约 2800)——后者会把置信度
  高估一个数量级。
- **训练方差**:同一配置跨种子最大差 0.125,单种子结果不可用于排序。
- **标注者一致性**:两位医生仅 45.7% 一致,故按软目标(0/0.5/1)处理。
- **`attn_align` 的分辨率**:注意力在 7×7 token 网格上评估,医生区域图渲染于
  28×28 后降采样。
- **概念对比损失近乎惰性**:A3 与 M0 无差别(p 未测但 macro 差 0.011),
  且梯度量级相差两个数量级(‖∇P‖=5.11 vs ‖∇F‖=0.101)。不宜列为独立贡献。
- **M1(冻结 CLIP 文本概念)相对 M0 无可验证优势**:5 个 prompt 的余弦相似度
  均值 0.877,本就难以区分。
