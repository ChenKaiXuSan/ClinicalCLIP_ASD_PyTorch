# LLM 把医生关注区域翻译成测量(2026-11-12)

**结论:按事先定的标准不成立(Qwen3-VL 2B / 4B / 8B)。** LLM 提出的测量集合 0.62–0.69,不高于随机抽列的 95 分位,
医生区域条件与未标区域条件、不给区域条件没有差别。原因很具体:LLM 几乎不提躯干倾角(300 个集合里 29 个),而它单列就是 0.707。

## 设计

论文链路里"区域 → 5 个量"是作者手工定的。这里让 LLM 做这一步:输入医生关注的区域名称与 18 个地标,在测量库的语法内
(地标对 × {incl, dx, dy, dz} × {mean, range};8 种关节角 × {mean, min, max, range})提出 5 个测量,几何代码照算。
LLM 不接触患者数据与标签;提示词是固定模板,不含任何具体测量的提示(`analysis/llm_measure_propose.py --print-prompt`)。

| 条件 | 区域 | 是否告知鉴别 ASD |
|---|---|---|
| marked_task / marked_blind | 腰椎骨盆、头、肩(医生标注) | 是 / 否 |
| unmarked_task / unmarked_blind | 膝、足踝、腕肘 | 是 / 否 |
| noregion_task | 不给 | 是 |

每条件 1 次贪心 + 20 次采样(T = 0.7),三个模型。评测 `analysis/llm_measure_eval.py`:67 人,患者值 = 测量库列的全段均值,
LR(C=1, balanced),10 份划分。判定标准(事先):医生区域条件 ≥ 0.70 且明显高于未标区域条件与随机对照。

## 结果(平衡准确率,20 个采样的均值 ± sd)

| 条件 | 2B | 4B | 8B |
|---|---|---|---|
| marked_task | 0.662 ± 0.045 | 0.672 ± 0.026 | 0.663 ± 0.032 |
| marked_blind | 0.656 ± 0.046 | 0.690 ± 0.017 | 0.678 ± 0.013 |
| unmarked_task | 0.682 ± 0.022 | 0.678 ± 0.032 | 0.664 ± 0.023 |
| unmarked_blind | 0.659 ± 0.036 | 0.616 ± 0.034 | 0.669 ± 0.038 |
| noregion_task | 0.658 ± 0.038 | 0.674 ± 0.023 | 0.690 ± 0.013 |

同口径参照:手工 5 量(库内 7 列)0.687,全库 L1 0.705,躯干倾角单列 0.707,随机 5 列 0.618 ± 0.080(95 分位约 0.73)。
300 个采样集合没有一个超过随机的 95 分位;最好的 0.739。输出合法率 92–100%。

诊断(`llm_diag.py`,作业目录):

- **LLM 不提躯干倾角**:含 `sh_mid–hip_mid` 倾角 / 偏移的集合 29 / 300,成绩 0.691 ± 0.013;不含的 0.665 ± 0.036。
  它偏好头-躯干夹角、鼻-耳连线、脊柱曲度这类"听起来像脊柱畸形"的量。
- **区域对照不可解释**:未标区域条件下,条目完全落在给定区域内的只有 5–38%,模型无视约束照样去量头和躯干。
  所以"医生区域 vs 未标区域"的差别在这组模型上测不出来。
- 模型尺寸没有趋势。

## 顺带发现:论文里"第 98 百分位"的说法需要修正

论文 Table 2 写"随机 5 量 0.627 ± 0.076,医生定义的 5 量在第 98–100 百分位"。那个百分位是拿**固定划分**上手工 5 量的 0.768
去比的;固定划分是运气偏高的一份(10 份划分是 0.717)。同一口径(患者级,每次 10 份划分,各 300 次)重算:

| | 随机 5 列 | 随机 7 列 |
|---|---|---|
| 分布 | 0.618 ± 0.080 | 0.621 ± 0.070 |
| 手工 5 量,库内 7 列 0.687 | 第 79 百分位 | 第 84 百分位 |
| 属性版 5 量 0.717 | 第 91 百分位 | 第 95 百分位 |

诚实的说法是"高于随机均值约 0.07–0.10,在第 80–95 百分位",不是第 98。另外在这个口径下躯干倾角单列(0.707)不低于手工 5 量的
7 列版本(0.687)。投稿前要按 10 份划分重算 Table 2 并改正文与摘要里的这句话。

## 下一步的选择

1. 换更强的纯文本 LLM 重跑(这一步不含患者数据,可以用外部 API):检验失败是"小模型不懂生物力学"还是"任务本身不行"。
2. 放宽形式:让 LLM 给 15–20 个候选,再由 L1 在候选内选。但全库 L1 也只有 0.705,上限很低。
3. 不做:接受"区域 → 测量"需要临床 / 生物力学专业判断,论文里如实写成人工设计,并加上修正后的随机对照。

# VLM 属性作为门控里的第三分支(2026-11-15)

**结论:不成立,而且换问题也救不了。** 用 9 月的 Qwen3-VL-8B 临床问答属性(`logs/qwen_attributes/`,8 个问题)做患者级 LR,
作为证据门控里的"备选意见"(`analysis/vlm_third_branch.py`,与 `uncertainty_fusion.run_one` 同一套嵌套流程,67 人)。

| 备选分支 | 备选单独 | 测量 | 固定 0.5 | 嵌套 w | 阶梯门控 | 任一判对上限 |
|---|---|---|---|---|---|---|
| 视频(9 组均值,现状) | 0.628 | 0.751 | 0.717 | 0.745 | **0.794** | 0.885 |
| VLM 属性 | 0.621 | 0.751 | 0.679 | 0.761 | 0.681 | 0.885 |
| 视频 + VLM 平均(9 组) | 0.673 | 0.751 | 0.764 | 0.757 | 0.801 | 0.879 |
| VLM 概率在患者间置换 30 次 | | | | | 0.751 ± 0.042 | |

起因是一个看起来有希望的数:测量判错的 17 人里 VLM 属性判对 10 人,"任一判对"上限 0.885。但门控下只有 0.681,
低于置换对照;与视频平均的 +0.007 在噪声内。

为什么(`analysis/vlm_third_strata.py`,按测量偏离度三分层):

| 层 | n(ASD) | 测量 | 视频 | VLM 属性 |
|---|---|---|---|---|
| 低偏离 | 23(20) | 0.392 | 0.641 | 0.467 |
| 中 | 22(11) | 0.864 | 0.646 | 0.545 |
| 高偏离 | 22(15) | 0.929 | 0.639 | 0.824 |

VLM 属性只在测量本来就对的高偏离层里对(0.824),在门控要让出去的低偏离层里是随机水平。视频在三层里都是 0.64,这才是互补。
低偏离层里 8 个 VLM 属性的单变量 AUC 全在 0.50–0.55。

感知检验(`analysis/vlm_third_percept.py`):VLM 的回答分数与同一段视频上几何测得的对应量的 Spearman(段级 / 患者级)——
头前伸 +0.60 / +0.67,手臂摆动 −0.31 / −0.46,步幅 −0.27 / −0.46,**躯干前倾 +0.17 / +0.39**,膝屈、髋伸展、骨盆后倾 ≈ 0。
VLM 看得见姿态,但它的回答是几何量的带噪副本,而且在最有诊断价值的躯干前倾上最弱、在没有诊断价值的头前伸上最强。
重新设计问题最多让它逼近几何量本身,带不来几何之外的信息。

至此 LLM / VLM 在这条流程里试过的位置:区域 → 测量定义(负面)、关键点质量检查(上限为零)、第三分支(负面)、
以及 9 月的骨干 / 指令 / 红框 / 蒸馏 / 零样本(负面)。未试且不涉及精度的只剩"按数字生成报告"。

# 换更强的开源 LLM 重跑"区域 → 测量"(2026-11-16)

**结论:上次的失败是模型太小。** 同一提示词、同一评测,换成 Qwen3-32B(思考模式)与 gpt-oss-20b(另一个家族)后:
医生区域条件追平手工 5 量,并且显著高于未标区域条件。但绝对水平没有超过手工设计,也没有超过随机对照的 95 分位。

| 条件 | Qwen3-VL-8B(上次) | Qwen3-32B | gpt-oss-20b |
|---|---|---|---|
| marked_task | 0.663 ± 0.032 | 0.682 ± 0.027 | **0.697 ± 0.012** |
| marked_blind | 0.678 ± 0.013 | 0.682 ± 0.039 | **0.693 ± 0.023** |
| unmarked_task | 0.664 ± 0.023 | 0.633 ± 0.043 | 0.598 ± 0.066 |
| unmarked_blind | 0.669 ± 0.038 | 0.604 ± 0.043 | 0.575 ± 0.051 |
| noregion_task | 0.690 ± 0.013 | 0.693 ± 0.026 | 0.693 ± 0.021 |
| 医生区域 − 未标区域(task / blind) | 0.000 / +0.009 | +0.049 / +0.078 | +0.099 / +0.118 |
| 上面差值的 MWU p | 0.67 / 0.80 | 1e-4 / < 1e-4 | < 1e-4 / < 1e-4 |
| 提出躯干整体倾角或偏移的比例(marked) | 0.20–0.25 | 0.35–0.45 | 0.50–0.55 |
| 条目完全落在给定区域内(marked / unmarked) | 0.72 / 0.36 | 0.69 / 0.14 | 0.83 / 0.40 |

同口径参照不变:手工 5 量 0.687(AUC 0.755),全库 L1 0.705,随机 5–8 列 0.61–0.64(95 分位约 0.73–0.75)。
AUC:医生区域条件 0.74–0.78,未标区域 0.62–0.68。gpt-oss-20b 的 40 个医生区域集合里 75% 不低于手工 5 量,Qwen3-32B 是 45%。
(`llm_diag2.py` 在作业目录;生成用 `pegasus/llm_measure_job.sh`,`MODELS=... MAXTOK=3500`,gpt-oss 需要
`PYTHONPATH=/work/1/SKIING/chenkaixu/pydeps/extra` 提供 accelerate。)

读法:

1. **这一步可以自动化而不损失**:只给区域名称与地标(marked_blind,不告知疾病),LLM 提出的测量就达到手工设计的水平,
   波动很小(gpt-oss sd 0.012–0.023)。论文里"5 个量是作者定的"这一环有了可复现的替代。
2. **医生区域确实携带信息**:同一模型、同一提示词,只把区域换成膝 / 足踝 / 腕肘,成绩掉 0.05–0.12,两个模型、有无疾病信息都成立。
   小模型看不到这个差别是因为它们不遵守区域约束。
3. **医生区域与 LLM 的疾病知识是冗余的,不是叠加的**:不给区域、只告知鉴别 ASD(noregion_task)同样是 0.693;
   两者都给也不更高。LLM 知道疾病就会自己去量医生看的那些部位。所以不能声称"医生标注提供了 LLM 不知道的东西",
   能声称的是"医生的关注区域与医学先验一致,且在不告知疾病时足以导出同等的测量"。
4. **没有超过人工,也没有超过随机的 95 分位**:医生区域条件在随机对照的第 73–81 百分位,和手工 5 量自己的位置(74–84)一样。
   事先定的标准"≥ 0.70 且明显高于两个对照"里,高于未标区域成立,≥ 0.70 差一点(0.68–0.70),高于随机只到均值以上。
5. LLM 仍然只有一半左右的采样提出躯干整体倾角(单列 0.707);它更常提头-躯干夹角与脊柱曲度。

局限:只有一个提示词模板、两个模型、67 人;"共识集"(最常出现的 5 个条目)0.69–0.72,可作为确定性输出的候选,未单独验证。
