# 主线与投稿计划(2026-09-13 确定)

## 主线

**医生标注的关注区域 → 决定从骨架上量哪些临床几何量 → 3D 关节点给出数值 → 独立、可读的几何分支 →
与视频分支在概率层融合。** 医生标注只用来选量,不进推理;几何分支保持线性、可读;融合在决策层。

证据链(全部在 `docs/vlm_backbone.md`,患者级 n=79,三种子):

| 环节 | 证据 |
|---|---|
| 医生选的部位有信息 | 医生部位 5 个量 0.78,未标部位 0.56–0.61,全部混在一起 0.72 |
| 几何量本身强 | 5 个数的逻辑回归 0.78,高于所有端到端视频模型(0.66–0.72)、ST-GCN(0.54)、全部 VLM 变体(≤0.63) |
| 与视频互补 | 概率融合 9 组(3 分支 × 3 种子)全部高于视频单独,均值 0.79,7 组显著 |
| 必须概率层融合 | 辅助回归 0/8 有效;特征拼接 1/8 稳定(G5-3D 0.715±0.008);都低于 0.78 |
| 3D 是更稳的版本 | 单独用与 2D 等价;融合 0.790 vs 0.757;躯干量 AUC 高 0.1 |

## 创新点(按强弱)

1. **医生注意力的角色重定义**:从"输入 / 监督信号"变成"测量方案的设计者"。区域标注信息量低
   (全库 6 种组合,两位医生一致率 45.7%),不该让网络学它,应由它决定量什么。有对照证据。
2. **反直觉的经验结论**:5 个有临床名字的数比端到端模型强。小样本步态诊断里,专家指导的测量胜过表示学习。
3. **先验怎么进模型的系统对照**:同一份几何量三种用法、三种子、两种骨架来源共 255 个运行——
   早融合失败、晚融合成功。弱但互补的信号必须在决策层融合。
4. **可追溯的解释**:每个患者的判断能写成"躯干前倾 X 度、髋屈曲 Y 度",是分类器的输入而非事后可视化。

次要:侧视单目视频 SAM-3D-Body 取 3D 关节量矢状面量(冠状面无信号,如实报);VLM 五个维度的系统性负面结果。

## MICCAI 需要的方法创新:从证据里长出来的两个方法

### 方法 1(核心):医生注意力先验引导的稀疏测量选择

现在的 5 个量是手挑的,审稿人必问"为什么是这 5 个"。做成可学习:

- 从 3D 关节自动生成**测量库**:关节对的矢状面倾角 / 前后偏移 / 高度差、运动链三元组的关节角,
  段内均值 / 极差 / 极值,几百个量;每个量按所涉关节归属到 5 个医生区域(foot / wrist / shoulder / lumbar_pelvis / head)。
- 分类器是稀疏线性模型,L1 惩罚强度**按医生区域先验分组**:医生标注频率高的区域惩罚小,未标区域惩罚大
  (实现:特征除以惩罚权重,再做普通 L1)。
- 对照:同一测量库 + 均匀 L1(无先验)、随机先验(多次置换)、反先验、只用医生区域(硬选择)、只用非医生区域、手挑 5 个。
- 判据:医生先验下选出的量更少、精度更高、跨折选择更稳定(Jaccard),则"医生注意力是有效的选择先验"在方法层面成立。
- 风险:均匀 L1 也能选出差不多的量。那结论退回"测量库本身够了",仍是分析论文——**先跑这个实验再决定投哪里**。

### 方法 2:不确定性感知的患者级融合

现在 w=0.5 / 0.7 是全局、事后挑的。改成每个患者一个权重,由几何分支的可靠性决定
(3D 缺帧比例、关节点置信度、测量值离群程度、几何分支预测熵;视频分支同理),门控在训练折上学。
干净的方法贡献,同时消掉最大的方法学漏洞。

### 方法 3(备选,风险高):临床概念瓶颈

视频分支只能通过预测的几何量分类。辅助回归实验已显示视频预测这些量对分类无帮助,不作主贡献。

## 执行顺序

1. 方法 1:测量库 + 分组稀疏 + 三种对照(逻辑回归级别,一两天)。分水岭。
2. 方法 2:患者级概率上实现,与固定权重、嵌套选择对比。
3. 两个都成立走 A;只有 2 成立走 B。
4. 必补:随机 5 量对照、逐区域消融、全部数字三种子 + 区间 + McNemar。

## 不再做的

VLM 任何形式的特征 / 提示 / 解释;把几何量塞进视频编码器;单种子比较。

## 方法 2 结果(2026-09-14)与决定

- 可学习的 6 特征 sigmoid 门控无效(退化成常数 w);**阶梯规则**"医生部位测量的平均 |z| 低于训练折 30–40 百分位 → 听视频,
  否则完全信几何"成立:手挑 5 量 + 视频 0.761 → 0.805(9 组),置换 0.762±0.014,未标部位的量 0.745,2D 算法 0.802。
- 对方法 1 的测量库(0.803)门控无收益(0.789):测量库已覆盖矢状面不明显的病例。
- 决定:走方案 A,但把方法 1 与方法 2 合成**一个方法**写——"专家注意力定义测量空间(硬边界),测量的证据强度决定何时信它";
  主管线报"5 个可读测量 + 证据门控融合 = 0.805",测量库 0.803 作为"自动选择等价于专家手挑"的支持实验。
- 下一步:MICCAI 稿件结构与图表;逐区域消融(去掉 lumbar / head / shoulder 各一)与随机 5 量对照仍要补。

## P0 / P1 对照后的修订(2026-09-14,细表见 `docs/vlm_backbone.md` "对照与鲁棒性")

- **撤回**宽松硬过滤 0.803:随机三区域不特殊、换划分 0.731、67 人子集反转。
- 方法 1 的成立形式 = **严格候选集**(两端地标都在医生区域,300 量):换划分 0.778±0.015,对补集 +0.085(10/10),对无边界 +0.029(8/10)。
  论文报换划分的数,不报固定划分。
- 方法 2 改为条件性主张:几何证据不足(医生部位测量不偏离常模,几乎全靠头前伸)时交给视频;几何分支 ≥0.79 时收益为零。
- 新发现进正文:**头部**是医生标注里最有价值的区域(严格消融 / 三区域排序 / 门控留一三处一致)。
- 基线补齐:2D / 3D ST-GCN 均随机(0.52–0.53);随机森林 / 梯度提升吃全库 0.73–0.77,不超过专家边界 + 线性。
- 待定:67 名完整 3D 患者上的 10 份划分(补跑中),决定 claim "优于补集" 能否保留。
