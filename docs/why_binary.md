# 为什么放弃三分类

任务从 ASD / DHS / LCS_HipOA 三分类改成 ASD vs non-ASD 二分类,原因是**三分类在
这个数据集上做不出患者级评估**,不是方法不行。这份文档保留证据,原始日志已删除。

## 数据集规模(fold 0 三份并集,已过滤含 "HipOA" 的患者名)

| 类别 | 段数 | 患者数 | 平均每患者 |
|---|---|---|---|
| ASD | 1045 | 54 | 19 段 |
| DHS | 585 | 16 | 37 段 |
| **LCS_HipOA** | **260** | **9** | 29 段 |
| 合计 | 1890 | 79 | |

按患者分组做 5 折三分划分之后,每折 test 里 LCS_HipOA 只剩 **1–2 个患者**,
train 里只有 4 个。macro 里这一类占 1/3 的权重,却压在一两个人身上。

## 结果:14 个配置全部落在多数类基线附近或以下

fold 0,患者互不相交,`train/val/test = 1132/367/391`。macro 的多数类基线是 **0.333**。

| 实验 | macro | LCS_HipOA 召回 |
|---|---|---|
| A2_no_presence | 0.394 | 0.005 |
| M0_concept_learned | 0.382 | 0.003 |
| D2_doctor2_only | 0.377 | 0.001 |
| B1_2dcnn | 0.359 | 0.000 |
| M1_concept_cliptext | 0.358 | 0.000 |
| B2_cnn_lstm | 0.333 | 0.000 |
| A3_no_concept_loss | 0.332 | 0.007 |
| A0_shuffle_region | 0.315 | 0.003 |
| B3_pose | 0.305 | 0.001 |
| B0_3dcnn | 0.290 | 0.000 |
| D1_doctor1_only | 0.273 | 0.000 |
| A1_no_grounding | 0.209 | 0.056 |
| B4_clip_old | 0.186 | 0.000 |
| A4_no_prior | 0.146 | 0.011 |

**没有任何模型能泛化到没见过的 LCS_HipOA 患者**(召回 0.000–0.056)。

## 与泄漏协议下的对照

同样这批配置,在修复前的划分(`magic_move` 患者级泄漏 + val 即 test)下:

| 实验 | 泄漏协议 | 干净协议 |
|---|---|---|
| B4_clip_old | 0.886 | 0.186 |
| B0_3dcnn | 0.775 | 0.290 |
| D1_doctor1_only | 0.786 | 0.273 |
| A0_shuffle_region | 0.736 | 0.315 |
| M0_concept_learned | 0.690 | 0.382 |

`magic_move` 给每个非 ASD 患者在 train/val 之间对搬一个片段,于是同一批 LCS/DHS
患者的其他片段同时出现在训练和评估里。泄漏**只发生在患者最少的两类**(ASD 被
显式跳过),所以"LCS 召回 0.98"实际是"认出了背过的那个患者"。

这也解释了为什么修复前的数字那么好看,以及为什么修复后跌得这么彻底。

## 结论

- 三分类要成立,LCS_HipOA 至少需要几十个患者。当前 9 个,补数据之前不用再试。
- 二分类 ASD vs non-ASD 把 DHS 与 LCS 合并,非 ASD 侧变成 25 个患者、每折 test
  有 6 个,勉强可评估。这是当前数据量下能诚实报告的最细粒度。
- 统计口径上仍需注意:指标算在**段**上(n≈2800),但有效样本量是**患者**
  (每折 test 17 人)。论文里必须写患者数,只写段数会严重高估置信度。
