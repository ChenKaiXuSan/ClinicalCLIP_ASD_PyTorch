# 第三个数据集 KOA-PD-NM:有视频的外部验证(2026-11-19,`analysis/koa/`)

目的:CARE-PD 只公开骨架,证据门控的第二个分支只能是骨架网络,门控在那里无效(`docs/carepd.md` 第 5 节)。
这里用一份**有 RGB 视频**的公开数据,检验两件事:(1)先验测量的流程能否原样搬过来;(2)门控的增益是否取决于第二个分支看的是像素。

**结论**:
1. 测量分支原样迁移:12 个先验量 + 逻辑回归,三分类平衡准确率 0.897,高于去背景的视频网络(0.852)、轮廓网络(0.786)和骨架网络(0.804)。
2. 第二个分支是像素时融合有增益,是关节点时没有:与 ASD 上的方向一致。骨架网络在二分类下单独与视频一样准(0.936 对 0.909),
   但它和测量错在同一批人身上(两者至少一个对的上限 0.939,视频是 0.977)——"不是像素"与"第二个分支太弱"在这里分开了。
3. 证据门控本身:在与 ASD 同形式的二分类任务上成立(去背景视频 +0.016,5/5 个种子,高于 90% 的偏离度置换对照);
   在三分类上融合有增益(+0.013),但门控与置换对照分不开,简单平均不比它差。增益都只有 1–2 名受试者的量级。

## 数据

KOA-PD-NM(Kour, Gupta, Arora 2020;Mendeley Data `44pfnysy89`,CC BY 4.0,README 注明仅限研究;本机 `/work/1/SKIING/chenkaixu/data/koa_pd_nm`,不入库):
膝骨关节炎 50 人(早 / 中 / 重 15 / 20 / 15)、帕金森 16 人(轻 / 中 / 重 6 / 7 / 3)、正常 30 人;每人左右各走一次,侧面,1920×1080,
相机固定在 8 米处,身上贴 6 个红色标记点,人脸已打码。191 个文件里 `015_NM_02.MOV` 在原始压缩包里就是 0 字节,可用 190 段、96 人。
受试者编号在每个严重程度组内各自从 001 起,受试者 = `<编号>_<疾病>[_<严重程度>]`;年龄、性别、身高抄在 `analysis/koa/demographics.tsv`。

**三个与类别绑定的采集差异**(不处理的话视频分支可以不看步态就分类):

| 差异 | 事实 | 处理 |
|---|---|---|
| 帧率 | KOA 98/100 段是 50 fps,正常组 51/59 段是 30 fps | 全部按时间重采样到 25 fps;测量一律用真实时间 |
| 背景 | 三组拍摄场地不同(KOA 的幕布后有窗格) | 人物分割后把背景置黑(主结果),另跑原图与纯轮廓 |
| 焦距估计 | MoGe-2 逐视频估计的焦距有约 8% 波动 | 三组的"人框高度 / 真实身高"都是约 500 像素每米,统一用 4000 px |

无法消除的:年龄(正常组平均 44 岁,KOA 47–62,帕金森 67–70)、性别与衣着(KOA 多为女性着传统服装,轻度帕金森组全是男性)。
参照:只用年龄 0.626,年龄 + 性别 + 身高 0.662。

## 流程

```bash
KOA=/work/1/SKIING/chenkaixu/data/koa_pd_nm
qsub -t 0-3 -v STAGE=detect,NCHUNK=4 pegasus/koa_pose_job.sh    # YOLOv8-seg:行走者、25 fps、人物居中 224 裁剪 + 掩码
qsub -t 0-7 -v STAGE=sam3d,NCHUNK=8  pegasus/koa_pose_job.sh    # SAM-3D-Body(sam_3d_body 环境),固定焦距,约 40 分钟
python analysis/koa/build_measures.py                            # 30 个步态周期量(与 CARE-PD 同一份代码)-> logs/koa/gait.pkl
qsub -v MODE=masked,SEED=42 pegasus/koa_train_job.sh             # 视频分支,MODE: rgb | masked | sil | skel;一个种子 5 折约 30 分钟
python analysis/koa/eval_gate.py [--binary]                      # 测量分支 + 门控
```

设定(都在看结果之前定下):
- 任务:NM / KOA / PD 三分类,受试者级平衡准确率;次要分析把 KOA 与 PD 合并成"异常"做二分类(与 ASD 同形式,视频分支的概率直接合并,不重训)。
- 划分:5 折按受试者分层,每折的开发集再切出 val(`common.splits`),测量、视频、骨架网络共用。
- 测量分支:受试者级特征 = 该受试者两段视频的均值;先验 12 量 = 帕金森的 8 量(与 CARE-PD 完全相同)+ 膝骨关节炎的 4 个教科书特征
  (膝屈伸幅度、膝幅度左右不对称、步长左右不对称、双支撑期);标准化 + 多项逻辑回归 C=1 balanced。
- 视频分支:与 ASD 的 B0 同一模型与训练设置(Kinetics 预训练 slow_r50,1 秒一段 8 帧,224,Adam 1e-4,50 轮,val 选 checkpoint),5 个种子;
  唯一不同是交叉熵按类别频率加权(三类 50 / 30 / 16)。
- 门控:网格、选择规则(平衡准确率,平手取 NLL 小的)、嵌套方式与 `uncertainty_fusion.py` 完全相同;对照 = 固定 0.5、嵌套全局 w、偏离度置换 200 次。

## 结果

**三组的测量值**(中位数,NM / KOA / PD):步速 1.09 / 0.67 / 0.44 m/s,步频 115 / 88 / 79,步长 0.55 / 0.40 / 0.29 m,膝幅度 61 / 48 / 44°,
摆臂 0.27 / 0.16 / 0.12 m,着地时足俯仰角 15 / 8 / 5°,躯干前倾 −1.9 / 0.3 / 3.0°,摆臂不对称 0.10 / 0.17 / 0.32。

**测量分支单独**(三分类,10 份随机 5 折划分)

| 集合 | 平衡准确率 |
|---|---|
| 先验 12 量 | 0.897 ± 0.027 |
| 只用帕金森的 8 量 | 0.847 |
| 只用膝骨关节炎的 4 量 | 0.782 |
| 全部 30 量 | 0.889 |
| 随机 12 量(200 次) | 0.839 ± 0.037,先验处于第 94 百分位 |
| 先验 12 量 + 年龄性别身高 | 0.925 |

逐组正确率:NM 0.93,KOA 早 / 中 / 重 0.80 / 0.95 / 0.87,帕金森 轻 / 中 / 重 0.83 / 0.86 / 1.00。

**第二个分支单独**(三分类,5 个种子):原图 0.968 ± 0.012;去背景 0.852 ± 0.046;轮廓 0.786 ± 0.049;骨架 ST-GCN 0.804 ± 0.034。
原图比去背景高 0.12,这部分来自背景,不能当作步态识别的成绩。

**门控的前提在这里成立**(三分类,按偏离度三等分的正确率):

| | 偏离度低 | 中 | 高 | 96 人里只有它对 |
|---|---|---|---|---|
| 测量 | 0.84 | 0.88 | 0.97 | |
| 视频,去背景 | 0.90 | 0.88 | 0.89 | 7.4 人(只有测量对 7.8) |

## 读法

成立:
- 流程(SAM-3D-Body → 步态周期量 → 先验集合 → 逻辑回归)不改一行就在第三种疾病组合上工作,并且比去掉捷径之后的视频网络、轮廓网络、骨架网络都高。
- **第二个分支读像素还是读关节点,决定了融合有没有增益**。三分类与二分类、ASD 与这里,四处方向一致。
  这里骨架网络单独并不弱(二分类 0.936),但与测量几乎错在同一批人身上,所以 ASD 上"骨架网络太弱"的混杂在这里被排除了。
- 二分类下阶梯门控高于所有对照(单分支、固定权重、嵌套权重、偏离度置换)。

不成立或证据不足:
- 三分类下门控与置换对照分不开,简单平均在去背景视频上还更高(0.921 对 0.912)。
- 所有增益都是 0.01–0.03,即 96 人里 1–2 人;单独看都达不到统计显著。能说的是"方向在三个数据集、两种任务形式上一致",不是"显著提高"。
- 测量分支已到 0.90,留给融合的空间本来就小;这份数据的三类差别很大(步速差一倍多),不是一个难的任务。

局限:三组的年龄、性别、衣着、场地都不同,去背景与轮廓只能去掉一部分;二分类是事后定的次要分析(主分析是三分类);
视频分支的二分类概率由三分类模型合并得到;每人只有两段视频。
