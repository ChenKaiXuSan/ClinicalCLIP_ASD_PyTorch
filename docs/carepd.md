# 在公开数据集 CARE-PD 上验证主线(2026-11-17,`analysis/carepd/`)

目的:MICCAI 稿的主张("临床先验定义少量测量,胜过端到端学习;与学习到的特征用证据门控互补")目前只在 67 名 ASD 患者上成立。
这里看它在另一种疾病上是否复现。**结论:流程可以迁移、测量可以由 LLM 自动导出、成绩有竞争力;但 ASD 上最突出的两个现象
(测量大幅领先端到端、证据门控有增益)在帕金森上都没有复现。**

## 数据与协议

CARE-PD(NeurIPS 2025 D&B,`vida-adl/CARE-PD`,CC BY-NC,仅限非商业研究;本机 `/work/1/SKIING/chenkaixu/data/care_pd`,不入库):
9 个队列的 SMPL 步态网格,4 个带医生评的 UPDRS-gait(0–3,按行走):PD-GaM 30 人 / 1700 次行走、BMCLab 23 / 781、
T-SDU-PD 14 / 381、3DGait 43 / 90。体型参数 beta 全部置零,所以 `smpl_fk.py` 用标准骨架做正向运动学即可(不需要 SMPL 模型文件)。
关节点转到逐帧身体坐标系(x 左右 / y 上 / z 前),对转身也成立。

- 测量库 `build_bank.py`:20 个地标两两的倾角 / 前后 / 高度 / 左右偏移 × {均值, 极差} + 13 个关节角 × {均值, 最小, 最大, 极差} + 骨盆速度,
  共 1573 个量,1 秒窗口统计后对整次行走取均值。语法与 ASD 的测量库相同。
- 评测 `eval_measure.py`:官方协议,逐队列留一受试者(自带折文件),按行走预测,各折拼起来算宏平均 F1(0/1/2)。
  标准化 + 多项逻辑回归(balanced, C=1),不调参。
- 官方深度基线(冻结运动编码器 + 线性探针;数字摘自论文,未重跑,口径可能有细微差别):PD-GaM 最好 0.73、BMCLab 最好 0.68;
  七个编码器均值 0.620 / 0.559 / 0.417 / 0.271。

## 读法

成立:
- 同一套流程换一种疾病可以直接跑通,12 个量 + 逻辑回归与端到端骨架网络同一水平:4 个队列里 3 个全量下更高,最小的队列(14 人)在每个样本量下都高 0.05–0.08。
- LLM 不靠人工导出的测量达到手写水平(大队列持平,小队列低 0.02–0.05)。
- 在小队列上,少量先验量明显好于把 1573 个量交给模型自己选(T-SDU-PD 0.51 对 0.36–0.37,3DGait 0.52 对 0.43–0.47)。

不成立:
- **没有 ASD 上那种悬殊差距**。ASD:测量 0.72 对骨架网络 0.49–0.54;帕金森:−0.04 到 +0.07。PD-GaM 上 8 名受试者之后网络就超过测量;
  在大规模动作数据上预训练的官方编码器更高(0.73 / 0.68)。
- **证据门控不迁移**:4 个队列里 3 个门控低于较好的单分支,偏离度置换后结果不变;只有 3DGait 有 +0.014。
- **选哪些量在帕金森上不重要**:PD-GaM 上随机 12 量 0.629 ≈ 先验 12 量。帕金森的步态损害是全身性的,几乎任何运动学量都与严重程度相关;
  ASD 的信号集中在躯干前倾一个量上。

含义:ASD 上的两个核心现象有它的特殊性(信号集中于一个静态姿态偏移、患者数极少、门控利用的是"不前倾的 ASD"这个亚群),
不能写成跨疾病的一般规律。CARE-PD 能支撑的说法是"流程可迁移、可由 LLM 自动导出、小样本下有竞争力且可解释"。

局限:官方基线数字未重跑;ST-GCN 是自己实现的普通骨架网络,只有 3–5 次重复;帕金森没有做"无关区域"的负对照。
