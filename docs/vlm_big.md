# 大 VLM(Qwen3-VL-32B)在流程里的三种用法(2026-11-17)

起因:换大模型后"LLM 把区域翻译成测量"从失败变成追平人工(`docs/llm_measure.md`),于是检验 VLM 是否也是"模型太小"。
三批实验,全部 67 人口径;训练类 50 轮 × 5 折,先 3 个种子(42 / 1337 / 2024),关键配置再追加 5 个(7 / 11 / 23 / 101 / 2025)。

**结论:大 VLM 带来的至多是 +0.02–0.04 的小增益,统计上没有确认;3 个种子时看到的两个"最高值"在追加种子后都回落了。
把医生知识写进 VLM 指令在三批里都没有帮助。**

## 一、VLM 看视频回答问题(8B → 32B,同一套脚本)

| | 8B | 32B |
|---|---|---|
| 回答与几何实测的相关(患者级):躯干前倾 / 头前伸 / 步幅 / 手臂摆动 | 0.39 / 0.67 / 0.46 / 0.46 | 0.42 / 0.74 / 0.57 / 0.50 |
| 带医生知识的零样本诊断,患者级 AUC(79 人) | 0.444 | 0.466 |
| 8 个回答分数 → LR,单独(67 人,固定 5 折) | 0.621 | 0.670 |
| 上者接证据门控 | 0.681 | 0.729 |

量变,没有质变。躯干前倾仍然看不准;零样本诊断仍在随机水平,且一个患者都不判为 ASD。接门控低于测量单独(0.751)。

## 二、VLM 特征 → 分类网络(冻结 VLM 的离线 token,`qwen` / `qwen_head` 组)

| 头 | 指令 | 8B | 32B |
|---|---|---|---|
| token 均值 + 线性 | generic | 0.540 | 0.534 |
| token 均值 + 线性 | clinical(带医生关注区域) | 0.545 | 0.514 |
| 概念交叉注意力(同 M0 的头) | generic | 0.583 | 0.624 |
| 概念交叉注意力 | clinical | 0.553 | 0.594 |

(3 种子。)尺寸对概念头有用(+0.04),对均值探针没用;带医生知识的指令不高于不带。32B 概念头 generic 用 8 个种子是 0.605 ± 0.047。

## 三、视频分支 + VLM 分支(`model.backbone=video_vlm`,`vvf` 组)

视频走 slow_r50,VLM 离线特征(时空均值 → LayerNorm → Linear → 256 维)走另一分支;feature = 特征拼接后分类,score = 两路概率平均。
实现:`project/models/video_vlm_fusion.py`、`project/trainer/train_video_vlm.py`,dataset 加 `cache_with_video`(缓存命中时仍解码像素),
冒烟 `tests/smoke_video_vlm.py`。

| 配置(3 种子) | 融合后 | 视频分支读数 | VLM 分支读数 |
|---|---|---|---|
| F2 32B generic,特征融合 | 0.693 ± 0.016 | 0.692 | 0.500 |
| F1 32B clinical,特征融合 | 0.646 ± 0.006 | 0.634 | 0.507 |
| F3 32B clinical,分数融合 | 0.571 ± 0.011 | 0.567 | 0.519 |
| F4 8B clinical,特征融合 | 0.596 ± 0.072 | 0.600 | 0.514 |

VLM 分支的读数(接在 detach 特征上的探针)在所有配置里都是随机水平:均值池化的 VLM 特征没有线性可读的诊断信息,融合后的成绩就是视频分支的成绩。

## 四、8 个种子的最终对比(`analysis/vlm_big_final.py`)

测量单独 0.751。"门控" = 该模型作为证据门控里的备选意见。

| 配置 | 单独(8 种子) | AUC | 门控(8 种子) | 原 3 种子 | 新 5 种子 |
|---|---|---|---|---|---|
| B0 3D CNN | 0.634 ± 0.042 | 0.675 | 0.798 ± 0.033 | 0.795 | 0.800 |
| M0 | 0.602 ± 0.068 | 0.635 | 0.791 ± 0.038 | 0.819 | 0.775 |
| F1 双分支 clinical | 0.631 ± 0.058 | 0.668 | 0.815 ± 0.015 | 0.816 | 0.815 |
| F2 双分支 generic | 0.664 ± 0.059 | 0.709 | 0.823 ± 0.019 | 0.829 | 0.820 |
| VLM32 概念头 generic | 0.605 ± 0.047 | 0.645 | 0.822 ± 0.036 | 0.850 | 0.804 |
| VLM32 概念头 clinical | 0.585 ± 0.034 | 0.617 | 0.814 ± 0.028 | 0.799 | 0.823 |
| B0 + VLM32 概念头(概率平均) | 0.621 | 0.697 | 0.810 ± 0.035 | 0.832 | 0.796 |
| F2 + VLM32 概念头(概率平均) | 0.648 | 0.718 | 0.837 ± 0.030 | 0.851 | 0.828 |

同种子配对差(8 对,Wilcoxon 双侧):

| 比较 | 均值差 | 为正 | p | 只看新 5 种子 |
|---|---|---|---|---|
| 单独:F2 − B0 | +0.030 ± 0.085 | 6/8 | 0.30 | +0.019 |
| 单独:F1 − B0 | −0.003 | 4/8 | 0.95 | −0.006 |
| 单独:M0 − B0 | −0.032 ± 0.070 | 3/8 | 0.25 | −0.062 |
| 门控:VLM32 概念头 generic − B0 | +0.023 ± 0.051 | 6/8 | 0.25 | +0.004 |
| 门控:F2 − B0 | +0.025 ± 0.045 | 5/8 | 0.20 | +0.019 |
| 门控:F1 − B0 | +0.017 ± 0.039 | 5/8 | 0.53 | +0.015 |
| 门控:M0 − B0 | −0.007 ± 0.050 | 3/8 | 0.55 | −0.025 |
| 门控:(F2 + VLM32 概念头) − B0 | +0.038 ± 0.031 | 6/8 | 0.031 | +0.028 |

读法:

1. **3 种子的最高值是挑出来的**。VLM32 概念头接门控 0.850 → 新种子 0.804;F2 单独 0.693 → 8 种子 0.664。配置之间的种子噪声是 ±0.03–0.05,
   3 个种子不足以分辨 0.03 的差距。以后比较端到端模型至少 8 个种子。
2. **有一个方向一致的小增益**:带 VLM 的几种备选意见接门控都在 0.81–0.84,高于 B0 的 0.798(+0.02–0.04),且双分支的种子间波动小一半(sd 0.015–0.019 对 0.033)。
   但单项都不显著;唯一 p < 0.05 的"F2 + VLM32 概念头"是事后组合,8 次门控比较做 Bonferroni 后不成立。更像是集成降方差,而不是 VLM 提供了新信息
   (VLM 分支读数随机、VLM 回答是几何量的带噪副本)。
3. **医生知识写进 VLM 指令没有用**:均值探针、概念头、双分支三处,clinical 都不高于 generic。
4. 双分支里分数融合(0.571)远低于特征融合,与项目里"决策级更稳"的规律相反:均值池化的 VLM 分支自己接近随机,概率平均直接被它拖累。

## 对论文的影响(未改论文)

- **M0 的两个数字在 8 个种子下不成立**:论文写 M0 单独 0.663、作门控视频分支 0.819("0.82 with the grounded model")。
  8 个种子是 0.602 ± 0.068 与 0.791 ± 0.038,都不高于 B0(0.634 / 0.798)。摘要与正文里的 0.82 需要改成"与 3D CNN 分支持平"。
  M0 的可解释性结论(注意力对齐 0.533)不受影响。
- B0 的门控 0.795 在 8 个种子下是 0.798,稳定。主数字 0.794(9 组均值)里含 M0 与 A1 的 3 种子值,需要用更多种子重算。
- 连同 `docs/llm_measure.md` 里的"第 98 百分位",论文目前有两处要修正。
